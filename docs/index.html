Installation & Security Guide

Follow the steps for your operating system. Because this is a beta release, your computer may display a security warning.

Before you install: Download HydraDesk only from the official links on this page or the official v0.1.0 GitHub release. Do not install a file received from an unknown person or third-party website.
Important: A security warning is not proof that an application is safe. If the downloaded file looks different from the official release, your security software reports malware, or you are unsure about its origin, stop and do not run it.

⊞ Windows installation

Step by step
  1. Click Download for Windows above.
  2. Open your downloaded HydraDesk-0.1.0-Windows.exe file.
  3. Follow the installer's instructions to complete the installation.
  4. Launch HydraDesk from the installed application or Start menu, if available.

If Microsoft Defender SmartScreen appears

Windows may show an “Windows protected your PC” warning because the beta installer does not have an established signing reputation.

  1. Confirm that you downloaded the installer from the official HydraDesk release linked on this page.
  2. If you cannot verify the file or have any doubt, choose the option to stop or cancel.
  3. Only if you have independently verified the official file and choose to accept the risk, Windows may offer More info → Run anyway. This is a risk decision, not a safety guarantee.

If Microsoft Defender or another security product specifically reports malware, do not bypass that warning. Stop and report the issue.

⌘ macOS installation

Step by step
  1. Choose the Apple Silicon or Intel download that matches your Mac.
  2. Open the downloaded .dmg file.
  3. If the disk image contains an app and an Applications shortcut, drag the app into Applications.
  4. Eject the mounted disk image when finished.
  5. Open HydraDesk from Applications.

If macOS says the developer cannot be verified

This beta build is not signed and notarized by Apple, so macOS may prevent it from opening.

  1. First, verify that the app came from the official HydraDesk release.
  2. If you trust the source and choose to proceed, open System Settings → Privacy & Security.
  3. If macOS offers an Open Anyway option for this app, review the warning carefully before using it. This option may not appear on every system.

If macOS says the app is damaged, or security software reports malware, do not automatically bypass the warning. Delete the download, obtain a fresh copy from the official release, and report the problem if it persists.

✓ Before you open the app

  • Downloaded the installer from the official HydraDesk release.
  • Selected the correct installer for your operating system and Mac processor, if applicable.
  • Checked that the filename matches the release asset.
  • Stopped if a security tool reported malware or another unexplained warning.
  • Understand that this is beta software and may contain bugs.

🛠️ Problems or feedback?

If installation fails, the app does not launch, or you encounter unexpected behavior, please report the details.

Include your operating system and version, the installer you downloaded, the steps you followed, and the exact error message. Screenshots can help, but do not include passwords or private information.

🔐 What the beta security warnings mean

HydraDesk v0.1.0 is distributed as an early beta. The macOS application is not signed and notarized, and the Windows installer may not have a recognized code-signing reputation. Operating-system warnings may therefore appear.

These warnings do not, by themselves, establish whether the application is safe or malicious. Downloading from the official release helps verify the source, but does not replace code signing, notarization, or independent security review.

Do not disable your system's security protections globally to install HydraDesk. If you cannot confidently verify the download, do not run it.
